# Jeong-Ah Yoon GitHub Pages

Simple academic-style GitHub Pages site for Jeong-Ah Yoon.

## Content Principle

Project ordering and role descriptions are based on `JeongAhYoon_CV.pdf`.
GitHub repositories are used only as supporting references for links and technical details.
Research is limited to ACS Lab and PathoBrainSeq, with ACS Lab written in greater technical detail.

## Suggested GitHub Pages Setup

1. Create or use the repository `jjyoon012-git.github.io`.
2. Place `index.html`, `styles.css`, and the `assets` folder at the repository root.
3. Push to `main`.
4. In GitHub Pages settings, publish from the root of the `main` branch.

## Main Sections

- Intro
- News
- Research
- Clickable project timeline with AI-focused stack highlights and screenshots
- Skills
- Awards and honors
